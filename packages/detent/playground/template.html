      Across three lists

      Lists that share a group name pass items to each other. Drop into an empty column and it takes the card.

      A list that scrolls

      Drag a card towards the top or bottom edge and the list scrolls to meet you, faster the closer you get. On touch this list still swipes normally — press and hold to lift instead.

        Without a mouse

        Tab to an item, then press space to lift it, arrow keys to move it and space again to drop. Escape puts it back. Each step is announced to screen readers.

          All of it at once

          Four panels on a canvas. Each one moves by its title bar and resizes from its bottom-right corner, both caged inside the canvas. Two of them hold sortable lists that pass cards between each other while the panels themselves are being moved.

          The edge you grabbed, and only that edge

          The same card in six host layouts, each with a bottom-right handle and nothing else. Pull the corner. Δleft and Δtop must stay 0 in all six — those edges were not grabbed. Only the first column is anchored to its top-left corner the way an absolutely positioned element is; the rest move on their own when their size changes, and the library has to cancel that out.

          Green is held, pink is moved. Any pink in the Δleft or Δtop row is the bug this bench exists for.

          A ratio inside a cage

          Aspect ratio locked, bounds set to the dashed cage, and only the four edge handles. An edge handle drives one axis and the ratio derives the other — and a derived axis has no edge you grabbed, so it grows about its own centre and has to fit on both sides. Pull any edge as far as you can: the panel should run out of room, never cross the dashes.

          n e s w

          Sitting it close to a corner is the interesting case — that is where the derived axis runs out of room first.

          A grid that does not start on the grid

          This panel is 190×110 with grid: 20, so its size is deliberately not a multiple of the step. Drag the left edge slowly. The edge must not move until the pointer has travelled half a step, and it must never move against the pointer.

          190 × 110

          A grid counted from zero would only ever reach 180, 200, 220 — so the first pixel of movement jumped 10px, sometimes the wrong way.
